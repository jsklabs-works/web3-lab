Lesson 6: The life of a transaction

A payment: sign it, wait, get put in a block, and anyone in the world can see it.

One real example

Key words
ETH (ether)
Ethereum's coin. You send it, and you pay fees with it.
Test network (testnet)
A practice copy of a blockchain whose coins are free and worthless.
Sepolia
Ethereum's main test network.
Block explorer
A website for looking up anything on a blockchain. Etherscan is the one for Ethereum.

On the Sepolia test network, someone (call them A) sent 0.0458 test ETH to someone else (B). That's all that happened. You can see it yourself, no login needed:

👉 View the transaction on Sepolia Etherscan

The only words you need

WordSimple meaningIn the example
Wallet / addressYour account; the address is like an account number you can shareA = 0xA9D2…
Private key / signatureYour secret pen; signing proves the payment came from youA signed "pay B 0.0458"
Fee (gas)A small charge to send, like a postage stamp0.000032 ETH
BlockOne page of the record book, holding many paymentsPage 11834561, 89 payments
HashA fingerprint; each page stores the previous page's, so old pages can't changeThe block links to the one before
ValidatorWhoever's turn it is to write the next page; earns the fees0xc6e2… wrote this page
NonceCounts how many transactions an account has sent: 0, 1, 2…This was A's transaction number 3, so their 4th

Why the nonce matters: it stops anyone from replaying an old signed payment to make you pay twice. Each nonce can be used only once.

On Etherscan

Key words
Transaction hash
A transaction's fingerprint. You use it to look the transaction up.
Confirmation
Each new block added after yours. More confirmations mean it's harder to undo.

On the transaction page, find: Transaction Hash (its fingerprint), Status, Block (click the blue number to see the block), From / To, Value, Transaction Fee, and the Nonce under "Click to show more". On the block page, Parent Hash (under "More Details") is the link to the previous block from Lesson 3.

Try it: send your own payment

Key words
Mempool
The waiting room where signed transactions sit until they're put in a block.
Fee (gas)
A small charge for a transaction, paid to whoever adds it to a block.
Gwei
A tiny unit of ETH used for fees: 1 gwei = 0.000000001 ETH.

Open Practice Ethereum, a pretend Ethereum with the same rules and no wallet needed:

  1. Send: Account 1 → Account 2, 1 ETH, then Sign and send. It waits as Pending, then a validator puts it into a block after about 5 seconds.
  2. Read it: click the payment's hash in Blocks to see the same fields as on Etherscan.
  3. Break a rule: try sending 500 ETH from Account 2. The network refuses.

Check yourself

After one payment, Account 1's nonce changed from 0 to 1. What will it be after one more payment from Account 1?

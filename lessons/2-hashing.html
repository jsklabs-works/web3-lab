Lesson 2: Hashing, a digital fingerprint

A hash turns any data into a short, fixed-length fingerprint. If the data changes, the fingerprint changes completely.

Key words
Data
Any information: text, numbers, a file, a whole ledger.
Hash function
A fixed recipe that turns any data into a short code. The same data always gives the same code.
Hash
The short code a hash function produces. It works like a fingerprint of the data.
SHA-256
The hash function Bitcoin uses. Its hash is always 64 characters long.

A hash function takes any data (a word, a whole notebook, a movie) and gives back a code of fixed length. Bitcoin uses one called SHA-256, whose code is always 64 characters long. Here are two entries that differ by a single zero:

Four properties

PropertyMeaning
Same input → same hashAnyone, anywhere, gets the identical code
Tiny change → totally different hashChange one character and the whole code changes
One-wayFrom the hash, you can't work out the input
Practically uniqueTwo different inputs never end up with the same hash

How this solves Lesson 1's puzzle

Each friend hashes their whole notebook and they compare just the 64-character codes. Same code → identical notebooks. Different code → someone changed something. Comparing thousands of pages now takes one second.

Try it: type and watch the fingerprint change

Key words
Hexadecimal
The characters 0 to 9 and a to f, used to write hashes and addresses.
SHA-256 fingerprint (always 64 characters)
Change one character and see how many of the 64 change.
  1. Change 50 to 500 and count the red characters.
  2. Change a lowercase letter to uppercase.
  3. Type a full paragraph. The fingerprint is still exactly 64 characters.
  4. Type A pays B 50 again. You get back the exact original fingerprint.

On your own computer

printf 'A pays B 50' | shasum -a 256

This prints b278e5a2…5647cd. Every computer in the world gets the same answer, so strangers can trust each other's fingerprints.

Bonus: websites store the hash of your password, not the password. If hackers steal the hashes, they can't reverse them.

Lesson 5: Mining, the cost of writing a page

Mining adds one new block at a time. It makes every block costly to create but instant to check, so rewriting history isn't worth trying.

Words in this lesson

Read these first. Each word is explained here before the lesson uses it. All words: glossary.

Mining
Creating the next block by solving a guessing puzzle, then adding it to the end of the chain.
Miner
A computer, or the person running it, that does mining.
Nonce (mining)
A number the miner keeps changing until the block's hash starts with enough zeros.
Difficulty
How hard the puzzle is, for example how many zeros the hash must start with.
Proof of Work
The rule that you may add a block only after showing you did the puzzle work. Bitcoin uses it.
Reward
What the block creator earns: newly created coins plus the fees from the block's transactions.
51% attack
Trying to rewrite history by controlling more than half of the network's power.
Proof of Stake
Another way to choose who adds blocks: people lock up coins as a deposit and get picked at random. Ethereum uses it.
Validator
Someone who has locked up coins and takes turns adding blocks in Proof of Stake.
Stake
Coins locked up as a deposit. Cheaters lose part of it.

Two questions are still open:

  1. From Lesson 3: a hacker can recompute every hash in milliseconds and rewrite history.
  2. Who adds the next block? If thousands of nodes all write pages at once, it's chaos.

Bitcoin's answer, Proof of Work, solves both: make adding a block require a lot of work, through a puzzle that's slow to solve but instant to check.

The puzzle

A block gets one extra field, the nonce ("number used once"), which is just a counter. The puzzle: find a nonce that makes the block's hash start with 0000. Hashes are unpredictable, so the only way is to try 0, 1, 2, 3… until you get lucky.

  • Mining is slow. Each extra 0 makes it about 16× harder. Four zeros takes about 65,000 tries on average.
  • Checking is instant. Anyone hashes the block once and sees it starts with 0000. No need to trust the miner.

Mining only adds blocks at the end

Definition: mining is the process of creating the next block. A miner collects waiting transactions, keeps guessing nonces until the hash meets the target, then shares the block. Everyone checks it with one hash and adds it to the end of the chain. Old blocks are never edited.

A hacker's attack: re-mining old blocks

To change block 2, the hacker must rebuild block 2 and every block after it, and each one has to be mined again. Meanwhile the honest miners keep adding blocks to the real chain:

Nodes follow one simple rule: trust the chain with the most work, which is usually the longest. The hacker's fake chain is behind, so everyone ignores it. To win, they'd need more computing power than all honest miners combined (a 51% attack), which for Bitcoin would cost billions.

Who earns what

Whoever solves the puzzle first adds the block and earns a reward: new coins plus the transaction fees. This is how new bitcoin come into existence, and it's why honest work pays better than cheating.

Quick note: Proof of Stake

Proof of Work (Bitcoin)Proof of Stake (Ethereum, since 2022)
To get a chanceSpend computing powerLock up ("stake") your own coins
Who is chosenFirst to solve the puzzleRandom pick, weighted by stake
What stops cheatingWasted electricityCheaters lose their staked coins

The goal is the same: adding a block must cost something, so cheating is a losing deal. Ethereum's block-adders are called validators instead of miners.

Check yourself

Mining a block takes a long time, but checking it takes one hash. Why is that combination exactly what a blockchain needs?

Show answer

Slow mining means every block costs real work, so rewriting history costs more than any hacker can afford. Fast checking means even an ordinary laptop can verify every block itself, so nobody has to trust the miners.

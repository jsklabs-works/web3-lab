# Web3 Lab

Hands-on practice files from learning blockchain, crypto and web3 step by step.

**Live site:** https://jsklabs-works.github.io/web3-lab/

| File | What it is |
|---|---|
| [practice-ethereum.html](practice-ethereum.html) | A pretend Ethereum in the browser: send ETH, watch blocks form, read transaction details. No wallet needed. |
| [token-dashboard.html](token-dashboard.html) | Connects to MetaMask and reads/sends an ERC-20 token on the Sepolia test network (ethers.js). |
| [mini-blockchain.js](mini-blockchain.js) | A tiny blockchain in one file: hashing, blocks, signatures, mining and tamper detection. Run with `node mini-blockchain.js`. |
| [MyToken.sol](MyToken.sol) | A minimal ERC-20 token written from scratch with line-by-line comments, for Remix. |

Everything here uses test networks or pretend money. Never share a seed phrase or private key.
